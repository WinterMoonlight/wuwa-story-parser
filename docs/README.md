## 研究与历史

- [专题研究目录](research/README.md)收录配置取证、规则验证及五轮阅读验收。
- `reviews/` 保存版本绑定的阅读审查JSON，配合 `export-review` 生成带结论的文件。
- `history/` 保存本次结构整理前的完整 `task_plan.md`、`findings.md` 和 `progress.md`。

项目根目录的三份规划文件提供当前状态，历史证据通过本页进入。
