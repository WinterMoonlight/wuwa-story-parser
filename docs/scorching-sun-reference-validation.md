## 通用实现

- `reference_diagnostics.py`：对静态清点中的缺失引用记录任务/回顾归属、精确语音关联和同事件候选；`replacement_applied=false`，不修改全局texts。
- 批量JSON的 `batch_coverage.missing_text_diagnostics` 保存证据，`missing_text`缺口保持。候选不计入可读正文数。
- TXT保留原可读材料，只增加一句“缺失文字虽有共用语音的候选文本，但尚未证实可以替换，仍保留缺失。”
- `investigate_flow.py` 可复现全库已解码引用扫描、相邻状态、语音冲突和来源哈希，不改变原始数据库。
