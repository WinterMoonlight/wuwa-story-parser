## 判定证据与规则

新增 `src/wuwa_story/text_refs.py`，导出器与批量静态清点共用类型判定。显式 NoTextItem、QTE 的 TidTalk 不作为对白，无论 TextId 或 PlotLineKey 是否残留；此前 Option 容器规则保持。普通 Talk 不因查不到文本、没有 WhoId 或空 PlotLineKey 而被排除。

NoTextItem 在全库既有空串，也有 dnt/无文本演出、说点什么吧和内部演出说明等内容。它们保存在 JSON 的 non_dialogue_controls 中，包括原始节点、文字、动作和路径，不伪装成角色台词；内部说明不自动改写成叙事。没有删除 Options 内真实的 TidTalkOption 引用。

QTE 的 QteSucceed/QteFailed 是运行结果，不能使用普通“任意选择一个选项”的策略。本轮明确阻止 Exporter 把 QTE 当普通选择执行；批量仍清点其分支材料，保留 QteId、条件和跳转，新增 qte_runtime_unverified 缺口。没有声称已支持 QTE 成功路线。
