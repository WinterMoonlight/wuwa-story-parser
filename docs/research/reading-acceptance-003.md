# 第三轮阅读验收

本轮核查《嘤鸣初相召》的场景过渡、叙述者配置和富文本显示，并联读万象新声上、下两项前置任务。

## 已确认的显示规则

WhoId83在db_speaker的NameStringKey指向存在的语言键，MultiText对应内容为空。旧字段索引为-1，其他语言同键也为空。配置只支持“无署名”状态。另一个明确命名为“旁白”的speaker100075具有不同的键和名称，不能借其名称替代83。全库83和1066满足当前空名判定。

SpeakerResolver与静态库存统一输出configured_empty_name，显示“无署名”，保留ID、名称键与来源。缺失键仍维持未解析状态。上篇2个主干事件、下篇0个、嘤鸣7个事件使用83。它们同时包含内心声音与叙述，读者可按文本理解，解析器不据文意指定人物。

阅读文本对合法color配对标签保留内容并移除样式，对ano标签保留正文与注释，例如葫芦〔终端〕。处理可重复执行，未知或破损标签、{0}/{q_count}等动态值保留。JSON中的原文与格式标签供溯源使用。

莫特斐被称赞之前的争执已提取在external_content[4]，安此亿兆生2/7有20句气泡对白。节点224先AddPlayBubble，随后异步PlayFlow1/3。配置支持气泡调用归属，但玩家是否完整听取、气泡完成与1/4交互的衔接未确认，因此保留环境对白的提示及候选位置。
