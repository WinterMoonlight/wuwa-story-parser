# 任务调用优先与补充片段恢复

## 执行口径

用户明确按任务调用关系恢复剧情，回顾作为缺少其他顺序依据时的补充。当前排序优先级为任务中的明确调用与完成依赖、实体或玩法的触发依赖、回顾顺序。优先级作用于已确认的引用对应关系，仍需保留分支、重复调用与异步作用范围。

“12条尚无整体顺序”指12条Type1记录的已有文本尚未连接成完整任务路线。其中《叩天关》《眠龙庭》已有局部有序片段，其他片段仍保留在材料中。该标签描述整任务的连接状态，具体片段分别保留解析结果。

## 补充片段的通用处理

|触发来源|当前可用依据|排序方式|
|---|---|---|
|任务完成调用|PlayFlow完成条件、FinishActions数组|前段完成后调用后段，符合支持形状时补入正文|
|实体交互|InteractComponent选项和前置条件|以任务完成、实体状态等依赖定位，保留可选性|
|地点触发|TriggerComponent、RangeComponent及唤醒销毁动作|先确定所属阶段，存在明确时间依赖时再定位|
|玩法触发|LevelPlay节点条件、动作与结束节点|恢复同节点调用顺序，再关联主任务完成条件|
|未选分支|选项跳转与条件|保留与该选项对应的分支，不按无条件正文串接|

现有模块已经读取这些来源。本轮扩展第一类，其他类别继续沿用已有支持与未定位记录。
