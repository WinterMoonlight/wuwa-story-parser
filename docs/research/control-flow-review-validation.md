# 三路控制流核查与统一整合

日期：2026-11-17。数据快照3.8.11；本轮不修改数据库或演出资产。

## 分工与结论

三个子agent先分别提交变量条件、分支状态、并行顺序证据；独立模块与测试由主agent复核后接入，核心解析器由主agent整合。

| 核查 | 通用改动 | 保留边界 |
|---|---|---|
| 变量条件 | 条件投影前拒绝已知同变量覆写、异步writer、明确中间状态控制；未知写入目标拒绝 | 未实现跨任意任务节点传播、Global Keyword、Int/String和外部写入求值 |
| 分支状态 | 阅读模式仅延迟未选SetVar/FinishState/ChangeState的预检拒绝，执行到仍须支持 | 不把FinishState/ChangeState当作无效果动作；严格模式、未知条件、QTE仍拒绝 |
| 并行顺序 | 相邻同步调用生成局部依赖；按全部回顾出现位置核查；多来源歧义保留 | 无跨并行分支排序、隐式回调或运行时完成证明 |
| 统一选择入口 | 显式choices同时传入普通路线与每个回顾段解析器 | 默认仍按原策略选择；非法/无法执行的选择不伪造成成功 |

详细取证：[变量条件](variable-condition-audit.md)、[状态分支](state-branch-evidence.md)、[并行顺序](parallel-order-audit.md)。

## JSON与TXT

- JSON的unverified_content/talk_groups保留unselected_control_actions、原始动作和未核验状态；全部原始分支仍在source_actions。
- conditional_selections.variable_guard保留允许投影的检查证据；拒绝时记录conditional_rejections，不改原segments。
- batch_coverage.order.dependencies包含edges、recap_dependency_consistent、recap_dependency_unresolved、recap_dependency_conflicts，以及各端全部出现位置。
- TXT只新增简短分支/顺序说明；不显示节点号、变量赋值、技术追踪。小游戏、字幕和外部正文保持原状。
