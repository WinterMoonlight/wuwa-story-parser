# 主线精简阅读版

## 本轮范围

按用户确认的主线顺读目标，默认TXT保留一条所选路线中的对白、选择、画面文字、资料正文和已排序字幕。复杂活动内部材料、失败结局、未选分支及未定位的补充内容保存在同名JSON中。

新增`mainline_reading`字段作为阅读投影。每条显示文字和省略说明均保存`source_pointers`，指向原有事件或资料。`write_result`写出这一投影及TXT，输入对象保持原样。`refresh-reading`仅重新生成TXT，原JSON字节保持不变。

排序沿用已有任务调用修正和回顾主干。该投影复用现有执行顺序解析结果。遇到缺失流程、未知交互或演出时原位保留短说明，接续已经提取的后文。活动结果直接保留源对白。
