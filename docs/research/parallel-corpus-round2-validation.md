# 第二轮三路取证与基础语料恢复

2026-11-17，3.8.11 数据快照。三个子agent分别核查动作参数、条件与分支、顺序与归属；先取证，由主agent统一整合，再交叉复核。原始数据库与资产未修改。

## 本轮规则与证据

1. PlayerLookAt：既有 Pos、CameraMove 形状增加可选的布尔 PlayAnimation。非布尔、未知字段、异步仍拒绝；沿用有限非负 Timeout 校验。JSON记录动画播放与完成尚未核验，不执行或解码资产。
2. 回顾段的局部常量写入：整段动作树仅含可识别的 Self Boolean 常量赋值，且不含条件、变量读取、状态结束、状态跳转或流程调用时，每次回顾出现位置创建独立变量环境。按实际选择记录写入，不跨段传播，不声称游戏初值和后续效果已确定。Global、Keyword、混合写入及控制流继续阻塞。
3. 单按钮静态 ConfirmBox：精确同步 OpenSystemBoard 调用，BoardId关联唯一配置；只支持已核验的五字段布局、空附加内容和唯一静态按钮。字段4是字符串向量，不能当整数ID；标题、正文、按钮均通过明确文本键关联，不能直接join语言库的数字Id。多按钮、动态格式、缺正文、超时、回调、未知参数继续拒绝。标题、正文、按钮标签按原调用位置显示为界面文字，不制造一次玩家选择；点击和关闭完成仍未核验。

ConfirmBox181实际引用 ConfirmBox_180_Title、ConfirmBox_181_Content、ConfirmBox_1_ButtonText_1，内容为长线任务提示。误用 lang_confirmbox.Id=181 会关联到另一条重启提示。
