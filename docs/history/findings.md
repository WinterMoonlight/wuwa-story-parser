## 数据关联

- QuestData：任务定义、Type、ChapterId；QuestNodeData：条件、父子节点、动作。
- QuestData.ChapterId → db_quest_chapter.questchapter.Id；QuestTree 的 ChapterId 是另一套章节树编号，不能混用。
- FlowListName + FlowId + StateId → flowstate.StateKey；BinData 中嵌有 JSON。
- TidTalk/TidTalkOption → MultiText.Id；当前加载 multi_text 后用 multi_text_1sthalf 同 ID 覆盖。
- WhoId → speaker；姓名先读 NameStringKey，再回退 BinData 字段 3，经中文 Speaker 表和必要的 MultiText 解析。
- PlotHandBook 为部分任务提供有序回顾列表。空 Flow 条目是提示；非空条目用于场景顺序。集合完全匹配是当前保守导出门槛。
- 项目现有回顾任务输出 task_audit.runtime_graph_executed=false；玩法条件视为已完成，原始假设保留。
