## 通用规则

新增task_flows.py，逐个引用保留路径、调用动作、父链及条件。只对所有出现位置均为已验证参数形状的AddPlayBubble.Params.Flow的任务独有流程，允许从回顾正文的覆盖比较中分离，并将已解码正文作为补充保留。

同一流程若还出现在正常PlayFlow或任务条件中，不允许移除；失败父链、未知参数、没有证据的引用也不套用此规则。这里没有硬编码任务ID、Flow名称或角色身份。任务条件中的流程不因存在DoInteract字样就被当作可选内容，正常动作也不被直接断言为必经剧情。

气泡用独立解析实例读取，避免继承主线人物绑定；保留源动作、原始触发参数、文本引用和哈希。TXT标为“靠近角色时的气泡对白”；批量分类中属于candidate_branch（候选回应及可触发对白），不表示玩家选择分支。存在选项时读取默认局部路线，尚不代表所有分支台词。
